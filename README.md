# Sri Sri Radha Krishna - Pre-Radhashtami Devotional Invitation

A cinematic, interactive devotional digital invitation for Sri Sri Radha Ashtami Mahotsav.

## Features
- **Cinematic Golden Line Animation**: Twin golden light ribbons swooping from darkness to form Sri Sri Radha Krishna.
- **Seamless 5.7s Transition**: Celestial golden bloom transition from the video directly into the authentic celebration poster.
- **Devotional Instrumental Music**: Background flute instrumental from Radha Krishna theme playing continuously.
- **Ambient Flower Petals**: Floating lotus and rose petals canvas overlay.
- **Interactive Lotus Feet Button**: Glowing sacred lotus feet with pulsing energy rings.
- **Personalized Invitation Card**: Blurs background poster and blooms the personalized invitation card showing Radharani's shower of blessings.
- **Devotee URL Parameter Personalization**: Supports dynamic personalized invitations via URL parameters (e.g. `?id=h.g.vamshi_mohan_prabhu` or `?name=Prabhu+Name`).

## Technologies
- HTML5, CSS3, JavaScript (ES6)
- HTML5 Canvas API & Web Audio API
- Responsive Mobile-First Design
